# 0003: Chat on, no data collection

Date: 2026-10-24
Status: Accepted by SHANNON (chat message)

## Decision

- Roblox's built-in filtered text chat stays on. The game builds no custom chat system.
- The game collects no personal data beyond what saves need: a player's coins, tier and pastry count, keyed to their Roblox user ID.
- No analytics or telemetry are stored in this pilot.

## Why

SHANNON chose to keep chat and avoid data collection. The audience is under 18, so the game relies on Roblox's own filtering and never stores chat content.

## Consequences

- The GDD's audience line is updated to match.
- Any analytics or custom chat is a new spec change with its own review.
