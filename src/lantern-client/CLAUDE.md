# Lantern Express client (LANTERN-007, architecture lantern 6)

| File | Owns |
|---|---|
| `ClientState.luau` | The Lantern theme passed to the shared `UiKit.configure` (art bible 7), `run()` (the `LanternRun` attributes, `Crew` and `Votes` decoded) and `RunChanged`, `profile()` (the `Profile` attribute through `LanternProgress.sanitize`), `request(action, arg)` with the refusal texts, `SFX` (registered ids only, nil plays nothing), rarity colours, `model(name)` (a `LanternAssets` model shared in `ReplicatedStorage.LanternModels`, else nil) and the part fallbacks named like the asset list, the `LanternPreviews` folder for album viewports, the train frame from `D` and `Speed`, the stop frame |
| `Menu.client.luau` | Start menu (logo, PLAY, the Ember Kit showcase, a slow orbit of the Depot), MENU in a run, and the panels ALBUM (GRID, WHERE with `LootRules.odds`, FOLLOWER), LOCKER (LIVERY, LAMP, BADGE), REWARDS (WEEKLY, MONTHLY, QUESTS), BOARD, SETTINGS (music, sound effects, Calm night, how to play) |
| `Hud.client.luau` | Lantern meter, phase chip with a calm progress bar (never a countdown), coal with tonight's need, Parts and oil, Tickets and the level ring, carry slots and DROP, SIT / STAND / STOKE / MEND, the crew list (badges, seats, pings), the Depot panel (upgrades, branch and weekly votes), the rescue reveal, the run end card, every toast |
| `PingWheel.client.luau` | Hold Q or the left bumper, or tap PING; six phrases; sends `ping <id>` or `ping <id>:<itemId>` (an `ItemId` attribute under the cursor); markers from `Fx ping` (8 s, 3 per player) |
| `LampFx.client.luau` | Turret control (mouse look, touch drag, right stick) with the aim kept in the train frame and sent on `Aim` (at most 10 a second, again every 0.3 s against the server's 0.5 s staleness); the local beam; other players' beams from their `lamp_turret_head`; wisps from `Fx wisps` with `WispRules.pos`; the Lampeater with `lampeaterPos`; puff, dim, dive, shoo and fed effects |
| `TrainFx.client.luau` | Lighting by phase (art bible 3), the seated camera sway, chimney smoke by speed, whistle and bell, the fog wall from `BellAt` with `TrainRules.fogFront`, the fog sprint vignette, the caught overlay, no jumping while seated on a moving train |

- The client never decides an outcome: it sends only the decision 0018 actions and a direction on `Aim`. The fog it draws never decides a catch.
- Every widget comes from the shared kit (`ReplicatedStorage.KitRoblox.UiKit`, configured by `ClientState`); require `ClientState` before the kit.
- Every animation checks `GuiService.ReducedMotionEnabled`; text stays at 12 px or more on an 844 x 390 screen (checked in Studio).
- Settled with the server at integration (LANTERN-012): the stop frame is the `Site` attribute of `Workspace.Lantern.Stop`; items carry `ItemId`; seats carry `Kind`; turret heads are named `lamp_turret_head`; the engine model is `train_engine`; `Carry` is JSON `{ small = { kinds }, big = kind?, help = itemId? }`; `LanternBoards` JSON is `{ critters = { { name, value } }, dist = { ... } }`; `runEnd.summary` has `critters`, `tickets`, `xp`; client models come from `ReplicatedStorage.LanternModels`. Music is `ClientState.MUSIC`, crossfaded by phase in `TrainFx`.
